# Connections, Auth & Feed Feature Module (Frontend)

**Owner**: Jatin  
**Scope**: Authentication, connection requests, user profiles, interests, and personalized feed.

## Structure:
- `components/`: UI components (LoginForm, RegisterForm, ConnectionButton, FeedItem, RequestCard).
- `services/`: API calls for auth, user profile, connection actions, and feed recommendations.
- `hooks/`: Custom React hooks for auth context, connections, and feed polling.
