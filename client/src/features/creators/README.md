# Creator Discovery Feature Module (Frontend)

**Owner**: Tushar Singh  
**Scope**: Creator listings, profiles, search, skills, and expertise filters.

## Structure:
- `components/`: UI components (CreatorCard, CreatorProfile, SkillBadge, SearchBar, FilterSidebar).
- `services/`: API calls for creators search, profile retrieval, and skill listings.
- `hooks/`: Custom React hooks for creator search and filter state.
