# Content Feature Module (Frontend)

**Owner**: Anvesha Patel  
**Scope**: Articles, short-form videos, books, categories, bookmarks.

## Structure:
- `components/`: UI components (ArticleCard, VideoPlayer, BookList, FilterTabs, BookmarkButton).
- `services/`: API calls for content fetch, category listing, and bookmark management.
- `hooks/`: Custom React hooks for content state management.
